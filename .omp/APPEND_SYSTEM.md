# STRICT PLANNING PROTOCOL
When you are operating in the 'plan' role to build a new feature or application within this project, you MUST NOT use any file-writing or execution tools immediately. 

Instead, you must first generate a highly detailed implementation plan that includes:
1. The proposed file and directory structure.
2. A comprehensive list of all function signatures, including parameter types and return types.
3. Any interfaces, data models, or schemas you plan to create.

Once you have presented this plan, STOP. Ask the user: "Does this plan look good, or would you like to make adjustments?" Do not proceed with implementation or tool calls until the user explicitly approves the plan.
